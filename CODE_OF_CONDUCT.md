# Code of Conduct

BrewDesk contributors must keep project spaces safe, respectful, and technically focused.

## Expected behavior

- Treat people with respect regardless of experience, identity, language, or background.
- Critique ideas and evidence rather than people.
- Keep reports reproducible, redact private data, and respect disclosure boundaries.
- Accept correction, explain tradeoffs, and help newcomers understand project constraints.

## Unacceptable behavior

Harassment, threats, discriminatory language, doxxing, deliberate exposure of credentials or private inventories, sexualized conduct, sustained disruption, and retaliation are not tolerated.

## Enforcement

Maintainers may edit or remove harmful content, restrict participation, or reject contributions. Until a public repository owner and private conduct-reporting channel are confirmed, do not include sensitive personal details in a public issue. A non-sensitive request for a private contact method may be posted after the public repository exists.

This project will record the final enforcement contact and any adopted external code-of-conduct version before public release.
