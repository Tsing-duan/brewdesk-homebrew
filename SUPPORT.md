# Support

BrewDesk is an unofficial public Alpha candidate. It is not a Homebrew support channel and does not provide a warranty or guaranteed response time.

For BrewDesk defects, use the repository's bug template after the public repository exists. Remove tokens, private inventories, user names, recipient information, proxy credentials, and sensitive absolute paths from logs. For potential vulnerabilities, follow `SECURITY.md` instead of opening a public technical report.

Questions about Homebrew behavior should first be reproduced with the command preview shown by BrewDesk. Consult Homebrew's official documentation for Homebrew-specific policy and support; do not imply that BrewDesk is endorsed by Homebrew.

Supported evidence for this candidate is Apple Silicon on macOS 26. Intel Macs and macOS 14 or 15 are not currently claimed as supported.
