# Open Source History

This repository is being prepared from a sanitized allowlist export of an earlier private working tree. Private distribution scripts, recipient data, tester data, manifests, generated artifacts, dependency directories, and build outputs are outside the public scope.

The initial public history will represent the reviewed public source candidate rather than reproduce private development history. This boundary is intended to avoid publishing material that was never approved for public release; it is not a claim that the project had no earlier private development.

No remote, tag, or Release is created during Stage A. After explicit release approval and publication, the public repository is intended to become the canonical source location. Until that happens, this statement is an intended transition rather than a completed publication fact.
