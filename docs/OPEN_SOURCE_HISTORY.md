# Open Source History

This repository began as a sanitized allowlist export of an earlier private
working tree. Private distribution scripts, recipient/tester data, manifests,
generated artifacts, dependencies, and builds remain outside the public scope.
The initial history represents the reviewed public candidate rather than all
private development; it is not a claim that earlier development did not exist.

The public repository became canonical with the first source prerelease,
[`v0.1.0-alpha.1`](https://github.com/Tsing-duan/brewdesk-homebrew/releases/tag/v0.1.0-alpha.1),
published on 2026-08-28. Subsequent fixes are recorded in its Git history.

Historical Stage A audit and launch documents retain their original context.
Their statements about unconfigured remotes or unpublished releases describe
that preparation stage, not the current repository. New source releases follow
[the maintenance release process](RELEASE_PROCESS.md); binary distribution still
requires separate approval and validation.
