# Screenshot Capture Guide

Only capture a real BrewDesk build that passed the current source and application-verification gates. Do not use browser mocks as a native-runtime screenshot.

Before capture:

1. Confirm the UI displays public Alpha wording and no private distribution controls.
2. Use a neutral package example whose name and metadata may be shown publicly.
3. Clear operation history and avoid installed-software inventories that identify the user's machine.
4. Hide user names, home-directory paths, computer names, proxy credentials, terminal history, account details, tester identities, recipient labels, private manifests, notifications, and unrelated applications.
5. Confirm rights for every visible icon, font, translated description, logo, and other asset.
6. Capture at native resolution without compositing unsupported features or success states.
7. Review the entire image at full size for sensitive pixels and misleading claims.

Record privately the application revision, macOS version, capture date, screen, rights basis, privacy reviewer, and any redactions. Public files should use descriptive names and alt text without embedding personal metadata. Remove unnecessary EXIF or location metadata before inclusion.

The retained Stage A search-screen screenshot completed these checks. Any replacement or additional screenshot must repeat the same content-rights and privacy review.
