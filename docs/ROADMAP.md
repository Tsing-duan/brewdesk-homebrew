# Roadmap

This is a bounded Alpha roadmap, not a delivery promise.

## Public source candidate

- Complete source and asset rights review.
- Confirm the final Bundle Identifier, Git identity, repository owner, and public metadata.
- Meet frontend, Rust, dependency-audit, secret-scan, external-build, and application-verification gates.
- Publish only after explicit approval, with the public repository becoming canonical after release.

## Later validation

- Gather real-user evidence for Chinese-first workflows and failure recovery.
- Expand application-origin test fixtures without weakening conservative conflict protection.
- Evaluate additional macOS versions or architectures only with real build and runtime evidence.
- Consider signed and notarized binary distribution only after its separate rights and release gates pass.

Cloud services, accounts, telemetry, AI features, and broad UI redesign are not part of the current public Alpha preparation.
